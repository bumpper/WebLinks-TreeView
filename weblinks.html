Set up cloud sync

Keep a synced copy of bookmarks.html in a cloud folder. Sign in to your provider, then choose the folder it syncs to on this computer. WebLinks writes the file there and keeps both copies matched each time you sync.

Open provider sign-in

The path is a reminder of where your cloud folder lives; the browser asks you to confirm the folder before anything is written. Bookmarks are only shared through the folder you choose.
